# Conduits

Pipes, ducts and cable runs. All of them are decorative: nothing flows through them.

| Block | What it is | Placement and properties | Use |
| --- | --- | --- | --- |
| Decor Pipe | A 6 px pipe | Connects to pipes on all six sides; flanges only at open ends | - |
| Pipe Valve | A pipe section with a handwheel | Any axis; joins pipes at both ends | - |
| Pipe Gauge | A pipe section with a dial | Any axis; joins pipes at both ends | - |
| Cable Tray | A shallow tray of cables | Mounts on any face; runs along an axis; joins end to end | - |
| Hanging Cables | Cables hanging from a ceiling | Stacks join into one run | - |
| Duct | A square duct | Any axis; joins end to end, seams only at the ends | - |
| Duct Fan | A duct end with a turning fan | Faces any of six ways; ends a duct run | - |
| Coolant Tube | A glowing glass pipe | Same bore as the decor pipe and joins it; Chroma block | - |
| Beam Emitter Prop | An emitter head with a lit lens | Faces any of six ways; draws no beam; Chroma block | - |

## Using them

- Decor pipes, valves, gauges and coolant tubes share one bore, so a single run can mix them.
- Use Pipe Brackets from the [Greebles](Greebles.md) to fix a pipe to a wall.
