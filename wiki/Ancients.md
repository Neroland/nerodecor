# Ancients

Weathered precursor architecture with dormant glyph technology. One invented alphabet runs through every
block.

| Block | What it is | Placement and properties | Use |
| --- | --- | --- | --- |
| Glyph Block | A carved stone block with a glowing glyph | Eight glyphs; neighbouring glyph blocks join into one cartouche | Empty hand: next glyph (sneak: previous) |
| Ancient Brick | Interlocking trapezoid brickwork | Random variants | - |
| Cracked Ancient Brick | The same brick, cracked | Random variants | - |
| Ancient Pillar | A pillar with capital and plinth | Any axis; a run gets a capital and plinth only at its ends | - |
| Dormant Core | A stone core with a dark lens | Wakes when powered by redstone: glows in its Chroma colour and gives light | - |
| Glyph Strip | A thin band of small glyphs | Mounts on any face; joins end to end; Chroma block | - |
| Arch Lintel | A corbelled half-arch | Faces you; left, middle or right piece, picked from its neighbours | - |

## Using them

- Build a cartouche from a wall of glyph blocks, then set each glyph by hand.
- Put a Dormant Core over a hidden redstone source to make it wake, or link it to a hub to choose its colour.

## Recipes

Ancient Brick is made from deepslate bricks and lapis; everything else starts from it (the cracked brick is
smelted). Full list: [Recipes](Recipes.md#ancients).
