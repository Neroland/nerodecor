# NeroDecor Wiki

Player- and contributor-facing documentation for **NeroDecor**, part of the Neroland ecosystem.
Built on **Neroland Core**.

> **Status:** beta — version `0.6.0-beta.1`. Hull/panel, glass and neon families with shape
> variants, connected textures and paint recolouring, plus the Luminous collection (0.4.0) and the Architect quest chapter (0.5.0).
> Pages will grow as features land. Keep this wiki updated alongside code changes
> (see [`../AGENTS.md`](../AGENTS.md) / [`../CLAUDE.md`](../CLAUDE.md)).

## Contents

- [Luminous Collection](Luminous-Collection.md) — the glowing, animated, connected signature set
  (circuit plating, holo-grid floor, starfield, aurora glass, void rift, plasma conduit, fusion lamp
  and more).
- [Architect Quests](Architect-Quests.md) — the optional NeroQuests chapter: 11 crafting and collection
  quests across every NeroDecor family.
- [Companion Link Module](Link-Module.md) — the read-only palette and block catalogue a NeroLink
  companion client can browse, and why it has no actions and no events.

Add one page per block, item, machine, or system as it is built, and link it here. Keep this page as
the index.
