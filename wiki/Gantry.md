# Gantry

Industrial walkways and structure. No lights and no block entities: everything you can see through (mesh,
grates, treads, the truss lattice) is a cut-out texture.

| Block | What it is | Placement and properties | Use |
| --- | --- | --- | --- |
| Catwalk | A 3 px mesh deck at the top of the block | Connects to neighbouring catwalks; the edge lip shows only on the outside of a group | - |
| Catwalk Stairs | Open-riser stairs | Face the high end, like vanilla stairs | - |
| Railing | Posts and rails | Connects like a fence; posts only at ends and corners | - |
| Gantry Ladder | A metal ladder | Mounts like a vanilla ladder; a run gets caps only at its ends; climbable | - |
| Floor Grate | A see-through grate cube | Connects on every side | - |
| Floor Grate Slab | The same grate as a slab | Bottom, top or double; connects sideways | - |
| Strut | A 4 px post | Any axis; joins end to end | - |
| Truss Beam | A hollow lattice beam | Any axis; joins end to end | - |

## Using them

- Catwalk decks sit flush with the top of the block, so they line up with floors, grates and the top tread of
  catwalk stairs.
- Pair railings with catwalks and hazard stripes along the edges.
