# Chroma Lights

Twelve light fittings made to be coloured by a [Chroma Hub](Chroma-Guide.md). Every one is a dark navy
housing with a near-white diffuser; only the diffuser takes colour, so the metal always stays metal.
Unlinked, a Chroma light shows a dim house cyan. Linked to a hub, it shows the hub's colour and plays its
scenes.

| Block | What it is | Placement and properties | Use |
| --- | --- | --- | --- |
| Light Strip | A 2 px glowing bar on any face | Mounts on the face you click; runs along the axis that continues a neighbouring strip; joins end to end | - |
| Edge Trim | An L-profile bar for the edge where wall meets floor or ceiling | Hugs the wall you face; top or bottom half; turns inner and outer corners by itself | - |
| Floor Tile | A dark tile whose inset seam glows | Connects to neighbouring floor tiles, so a floor reads as one panel | - |
| Floor Tile Slab | The same tile as a slab | Bottom, top or double; connects sideways | - |
| Step Light | A glowing stair nosing | Faces the way it lights; sits on the edge of a tread | - |
| Ceiling Coffer | A recessed 3 px light tray | Neighbouring coffers merge into one long trough | - |
| Light Pillar | An 8 px diffuser column | Any axis; a run gets end caps only at its ends | - |
| Neon Tube | A 2 px tube on standoffs | Mounts on any face; bends at corners by itself | - |
| Light Pane | A pane that glows | Connects like a glass pane, and above and below | - |
| Sconce Bar | A short wall bar | Hangs on the block behind it | Empty hand: switch between horizontal and vertical |
| Halo Ring | An octagonal hanging ring | No properties | - |
| Cage Lamp | A caged bulb | Mounts on any face | - |

## Using them

- Link the lights to a hub with the Chroma Linker, then colour them in the hub editor. See the
  [Chroma guide](Chroma-Guide.md).
- The [Paint Gun](Chroma-Cube-And-Paint-Gun.md) recolours paintable blocks (hull, panels, glass, Chroma Cubes);
  these fittings take their colour from a hub instead.
- Most Chroma lights are crafted from Chroma Cubes.

## Recipes

Strips, trims, tiles and panes make 4 to 8 per craft from Chroma Cubes plus iron nuggets, smooth stone or
glass panes; the floor tile slab also comes off the stonecutter. Full list: [Recipes](Recipes.md#chroma-lights).
