# Seven Worlds

Twenty-four building blocks, three or four for each of the seven Nerospace worlds. They are named after those
worlds only: NeroDecor does not need Nerospace installed. Each block has its own texture idea, not a recolour,
and none of them is a Chroma block: a world keeps its own palette.

| World | Blocks |
| --- | --- |
| Station | Station Plating (pale hull plates; connects, so seams and bolts sit on the outside of a group), Station Tread Plate (diamond tread with a worn lane), Station Thermal Blanket (quilted foil) |
| Luna | Luna Regolith Brick, Luna Bootprint Tile (raked dust; prints scatter at random), Luna Mare Column (basalt columns, any axis), Luna Bead Glass (dust set with volcanic glass beads) |
| Mars | Mars Rust Plate, Mars Wind Strata Brick, Mars Spherule Stone, Mars Dust Drift Tile (the drift banks into one corner; it faces you) |
| Cindara | Cindara Ember Basalt (cracks that breathe orange), Cindara Slag Brick, Cindara Ash Tile |
| Glacira | Glacira Bubble Ice (clear, connects), Glacira Cryo Fin (radiator fins, any axis), Glacira Frost Plate, Glacira Snow Brick |
| Greenxertz | Greenxertz Woven Chitin, Greenxertz Spore Tile (a few glowing spores), Greenxertz Hive Comb |
| Nyxara | Nyxara Faceted Crystal, Nyxara Shard Mosaic, Nyxara Geode Block |

## Using them

- Several flat tiles pick a random variant per block so a floor does not repeat.
- The [World Globe](Holo.md) shows the same seven worlds; the showroom's museum bay puts each world's blocks
  behind its globe.

## Recipes

Each world has one crafted base block from vanilla stand-ins for its rock; its other blocks come off the
stonecutter one for one. Full list: [Recipes](Recipes.md#seven-worlds).
