# Command

Consoles, wall screens, racks and operator furniture for a bridge or a server room.

| Block | What it is | Placement and properties | Use |
| --- | --- | --- | --- |
| Command Console | A sloped desk | The operator stands on the side it faces; a row joins into one desk with end cheeks; turns inner and outer corners (both hands) by itself | - |
| Wall Screen | A 2 px display panel | Mounts against a wall, facing you; screens next to each other form one N x M display (up to 16 a side) | - |
| Keyboard Shelf | A keyboard on a shelf | Faces you | - |
| Operator Chair | A swivel chair | Turns to face whoever placed it, in eight directions | Empty hand: sit down |
| Server Rack | A rack of blinking servers | Faces you; stacks join into one tall rack | - |
| Drive Rack | A rack of drive bays | As the server rack; reads differently at a distance | - |
| Patch Panel | A thin plate of patch cables | Mounts against a wall; a horizontal run joins | - |
| Blinkenlight Panel | A grid of lamps running a data pattern | Cube; Chroma block | - |

## Using them

- **Wall screens** show an idle animation drawn across the whole group, so a 3x2 screen reads as one display.
  The group's anchor tile (its lowest corner) accepts Neroland Core `link.display` pushes and draws the pushed
  text, icon and status colour across the whole group.
- **Sitting.** Use an Operator Chair with an empty hand to sit; sneak to stand up. The seat disappears when you
  stand or the chair is broken.
- Server and drive racks stack vertically; build them two or three high.
